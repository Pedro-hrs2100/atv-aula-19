## README: useEffect


## EXPLICAÇÃO DOS EXEMPOS QUE FORAM ESCOLHIDOS:


## Exemplo 1 (Mostrar um alerta quando a página carregar): 
## Este exemplo usa useEffect para exibir um alerta assim que o componente for carregado.

Explicação:
-O useEffect executa a função assim que a página carregar.
-A função mostra um alerta com a mensagem "Página carregada!".
-O [] (array vazio) garante que o alerta apareça apenas uma vez.

## Exemplo 2 (Contador que muda a cor do fundo): 
## Este exemplo cria um contador e muda a cor do fundo da página quando o número for par.

Explicação: 
-Criam um estado de contagem, começando em 0.
-useEffect altera a cor de fundo sempre que a contagem muda.
-Azul quando uniforme.
-Os números ímpares são vermelhos.
-Este botão aumenta a contagem e ativa o efeito.
